<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Browser -> login/session API | Credentials, bearer tokens, role-shaped client state, and patient IDs are untrusted. |
| FastAPI -> SQLite identity store | Password digests, active status, roles, and assignments control access. |
| API -> protected monitoring mutation | A valid identity crosses into persistent synthetic observation state. |
## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Spoofing | JWT login/dependency | high | mitigate | PyJWT verification with fixed algorithm, expiry, configured secret, and database subject lookup. |
| T-02-02 | Elevation of privilege | role/patient/assignment policy | high | mitigate | Closed role enum plus server-side policy dependencies and direct API denial tests. |
| T-02-03 | Information disclosure | protected patient routes | high | mitigate | Authenticate before resource lookup and enforce patient/assignment scope. |
| T-02-04 | Information disclosure | password/session contracts | high | mitigate | Salted scrypt digests, generic login failure, no password fields, and client clearing on 401/logout. |
| T-02-SC | Tampering | PyJWT install | high | mitigate | Blocking legitimacy checkpoint against the official PyPI project before installation. |
</threat_model>
