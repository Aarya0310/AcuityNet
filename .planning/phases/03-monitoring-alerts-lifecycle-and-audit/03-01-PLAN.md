| API caller -> protected alert read | Bearer-authenticated roles request patient-scoped evidence. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Tampering | Alert snapshot/effective settings | high | mitigate | Load typed settings and prediction once in the transaction; persist immutable evidence and rule version. |
| T-03-02 | Denial of service | Active episode creation | high | mitigate | Database uniqueness plus transaction conflict reload prevents alert storms and unbounded duplicate rows. |
| T-03-03 | Information disclosure | Current alert route | high | mitigate | Apply existing identity, patient, and assignment policy before resource query and return only typed scoped DTOs. |
| T-03-SC | Tampering | Existing package/runtime dependencies | high | mitigate | Reuse audited dependencies only; no new package install is planned. |
