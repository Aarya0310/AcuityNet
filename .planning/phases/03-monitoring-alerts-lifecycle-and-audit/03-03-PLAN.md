<threat_model>
| Boundary | Description |
|---|---|
| browser -> WebSocket handshake | Client transport attempts to subscribe to patient-scoped invalidations. |
| WebSocket message -> query cache | Untrusted notification data may influence refetch behavior. |
| browser -> REST alert/audit reads and commands | UI requests authoritative scoped resources and mutations. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-08 | Spoofing | WebSocket handshake | high | mitigate | Reuse bearer identity and patient/resource policy; close unauthorized or malformed subscriptions. |
| T-03-09 | Tampering | Realtime envelope/client state | high | mitigate | Treat socket payload as invalidation identity only; refetch authoritative REST contracts and validate message shape. |
| T-03-10 | Information disclosure | Alert/audit UI and socket scope | high | mitigate | Scope subscription and REST queries through existing role/resource policy; retain no secret payloads. |
| T-03-11 | Denial of service | Reconnect loop | medium | mitigate | Bound backoff, stop on unmount/logout, and never open a persistent session-level database connection. |
| T-03-SC | Tampering | Existing package/runtime dependencies | high | mitigate | Use FastAPI/Starlette and installed TanStack Query only; no new package install. |
</threat_model>
